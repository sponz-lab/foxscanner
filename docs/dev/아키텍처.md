# 아키텍처

## 데이터 흐름

```
회사 시스템 (ag-Grid)
   │  북마클릿 listgrab.js  (__agComponent 로 그리드 데이터 읽기, iframe 포함)
   ▼
index.html  ──(Firebase 익명 로그인)──▶ Firestore
   ▲                                   stores/{매장}/sessions/{전표}
   │ 휴대폰: 참여 QR                     └ counts/{기기}  (기기별 수량)
   │ 카메라(ZXing)/BT 스캐너
   ▼
반품: 북마클릿 returnfill.js 가 박스번호·처리수량을 전산 칸에 채움 (저장은 사람이)
```

## 핵심 규칙

- `config.js` 는 일반 스크립트. `import`/`initializeApp` 금지. 비우면 Firebase 없이 기기별 검수.
- Firestore 문서에 필드를 추가하면 [보안안내.md](../admin/보안안내.md) 규칙의 `hasOnly` 목록도 고친다.
- 북마클릿은 ES5, 자기완결형. 열은 한글 헤더 정규식(`HEAD`)으로 찾는다.
- `listgrab.js`/`returnfill.js` 를 고치면 `bookmarklets.js` 의 문자열과 `북마크모음.html` 도 같이 고친다 (자동화 없음).
- `index.html` 안의 QR(qrcode-generator 1.4.4)·ZXing(0.21.3) 블록은 수정하지 않는다.
- 상태 저장은 `index.html` 의 localStorage 래퍼를 쓴다.

## 배포 산출물

`scripts/build.sh` 가 앱 파일만 `dist/` 로 복사하고 `deploy/_headers`, `deploy/robots.txt` 를 함께 넣는다. 파일을 추가하면 이 스크립트의 `cp` 목록에도 추가해야 배포된다.
