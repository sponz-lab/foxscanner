# 배포 안내 — 무료 호스팅

이 앱은 정적 파일뿐이라 어디든 올릴 수 있습니다. 저장소가 **비공개**이므로 GitHub Pages(Pro/Team 유료)는 제외합니다. 데이터(실시간 합산)는 호스팅과 무관하게 Firebase 가 맡습니다.

## 어디에 올릴까

| 호스팅 | 비공개 저장소 | 대역폭 | 비고 |
|---|---|---|---|
| **Cloudflare Pages** (권장) | 가능 | 무제한 | 자동 배포, `*.pages.dev` |
| Netlify | 가능 | 월 100GB | `netlify.toml` 포함 |
| Firebase Hosting | 가능 | 월 10GB | 이미 쓰는 Firebase 프로젝트와 한 곳에서 관리 |

모두 `bash scripts/build.sh` 로 만든 `dist/` 를 올립니다. 문서·스크립트는 `dist/` 에 들어가지 않습니다.

## A. Cloudflare Pages (권장)

1. <https://dash.cloudflare.com> → **Workers & Pages → Create → Pages → Connect to Git**
2. GitHub 연결 후 이 저장소만 허용
3. 설정: Branch `main` · Build command `bash scripts/build.sh` · Output `dist` → **Save and Deploy**
4. 주소: `https://<프로젝트이름>.pages.dev/start.html`

> 로컬 브랜치가 `master` 라면 `git push origin master:main` 으로 올리거나 Branch 를 `master` 로 지정합니다.

## B. Netlify

**Add new site → Import from Git** → 저장소 선택. `netlify.toml` 이 빌드 명령과 `dist` 를 지정합니다.

## C. Firebase Hosting

```bash
npm i -g firebase-tools
firebase login
bash scripts/build.sh
firebase deploy --only hosting --project <프로젝트ID>
```

## 배포 후 체크리스트

- [ ] **Firebase 콘솔 → Authentication → Settings → 승인된 도메인**에 새 주소를 추가
      (빠뜨리면 익명 로그인이 막혀 여러 기기 실시간 합산이 조용히 죽습니다. 증상: 앱은 열리는데 다른 기기 수량이 안 보임)
- [ ] `<주소>/start.html` 이 열리고 QR·북마크가 새 주소로 만들어진다
- [ ] 휴대폰에서 카메라가 켜진다 (https 필요)
- [ ] [보안안내.md](../admin/보안안내.md) 의 Firestore 규칙 게시
- [ ] App Check 를 쓰면 reCAPTCHA 도메인에 새 주소(`<이름>.pages.dev`) 추가
- [ ] 매장 PC 북마크는 새 주소에서 다시 받아 설치 (옛 주소로 만든 북마크는 옛 주소로 열림)

### 북마크 주소는 빌드가 맞춰 줍니다

북마크릿은 `javascript:` 주소 안에 앱 주소를 품고 있어서, 호스팅 주소가 바뀌면
이미 설치된 북마크는 옛 주소를 계속 엽니다. `scripts/build.sh` 는 `SITE_URL`
(Cloudflare Pages 의 `CF_PAGES_URL`, Netlify 의 `URL` 도 자동 인식)을 보고
`북마크모음.html` 을 그 주소로 다시 만듭니다. 손으로 만들려면:

```bash
python3 scripts/make-bookmarks.py https://<새주소>/
```

주소를 바꾼 뒤에는 매장에서 `start.html` 의 북마크를 **다시 받아 설치**해야 합니다.
